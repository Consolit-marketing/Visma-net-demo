Visma Net demo — voorbeeld-embedding

Zo ziet de interactieve demo eruit wanneer je 'm met een iframe op je website plaatst. Hieronder staat de demo live ingeladen, gevolgd door de code die je kopieert.

Deze pagina laadt de demo in via src="index.html" (relatief, want de bestanden staan hier naast elkaar). Op je eigen website vervang je dat door de volledige URL waar je de demo host.

De embed-code (kopieer dit naar je website)

<!-- Visma Net interactieve demo — aangeboden door Consolit -->
<div style="position:relative;width:100%;max-width:1180px;margin:0 auto;
            border-radius:12px;overflow:hidden;box-shadow:0 8px 30px rgba(16,38,51,.14)">
  <iframe
    src="https://JOUW-DOMEIN.nl/visma-net-demo/index.html"
    title="Visma Net interactieve demo"
    style="width:100%;height:860px;border:0;display:block"
    loading="lazy"
    allow="clipboard-write">
  </iframe>
</div>
  1. Host de bestanden. Zet de map met index.html en de map assets/ op je webserver/CMS (of op GitHub Pages / Netlify / Vercel).
  2. Vervang de URL. Zet in de src het volledige adres waar index.html staat, bijv. https://www.consolit.nl/visma-net-demo/index.html.
  3. Plak de code in je pagina (in WordPress: een "Custom HTML"-blok).
  4. Hoogte aanpassen? Verander height:860px naar wens (de demo heeft zijn eigen interne scroll).
